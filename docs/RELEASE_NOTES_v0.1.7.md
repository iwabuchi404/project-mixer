# Project Mixer v0.1.7

複数プロジェクトの AI エージェント・ターミナル・ファイルを1つのウィンドウに集約するデスクトップアプリ。

v0.1.0 から v2 ブランチで進めてきた Phase 0〜8・構造リファクタリング（R0〜R4）が完了し、マルチペイン・CodeMirror 6 エディタ・検索バー・ローカルブラウザ・エージェント通知・セッション復元を統合した統合ワークベンチ UI が完成しました。

![Main View](screenshots/main-view.png)

## v0.1.0 からの主な変更

### 新機能

- **マルチペイン レイアウト**（Phase 8）: メインエリアを縦横に分割し、複数のターミナル・ファイルを同時表示（最大4ペイン）。タブはペイン間ドラッグ&ドロップで移動。`Ctrl+\` で分割、`Ctrl+1`〜`Ctrl+4` でペイン切替
- **CodeMirror 6 エディタ**（Phase 4.5）: ファイル編集・スクラッチ Composer を CodeMirror 6 に移行。タブ切替で undo 履歴・カーソル・スクロール位置を保持。`Ctrl+D` マルチカーソル、`Alt+click` 矩形選択、行ハイライト
- **検索バー**（Phase 5）: エディタ・プレビュー・スクラッチ共通の検索バー（CodeMirror 検索へ委譲）。`Ctrl+F` で開く
- **ローカルブラウザ**（Phase 4）: `localhost` / `127.0.0.1` / `[::1]` の開発サーバーをアプリ内 webview で開く
- **統合ワークベンチ UI**（Phase 4）: ターミナル・編集・ファイルプレビュー・ローカルブラウザを中央のメインタブへ統合。デザインシステム（トークン・カスタムタイトルバー・共通タブ表現）を導入
- **エージェント通知**: Claude Code / Codex / OpenCode の入力待ち状態をタブのバッジで表示。OpenCode はプラグインブリッジ方式に移行
- **セッション履歴復元**: 前回のエージェントセッションを自動復元（File メニューから ask / auto 切替）
- **OpenCode CLI サポート**: OpenCode をサポート対象に追加
- **コマンド層・MCP 統合**（Phase 1〜3）: コマンドレジストリ、`get_focus` / `show_file` MCP ツール、送信時のフォーカスコンテキスト付与
- **キーバインドレジストリ**（Phase 5）: `when` context を持つキーバインドテーブル。ツリーフィルタ（`/` で絞り込み）、プロジェクト検索（`Ctrl+Shift+F`）
- **スクラッチ Composer**: 画面下部に常設の編集領域。選択範囲を `Ctrl+Shift+Enter` で `path:L10-L20` 形式で挿入

### 改善

- **bracketed paste 動的切り替え**: TUI の bracketed paste mode 状態を xterm.js 公開 API で実行時に判定し、有効なら `\n` を変換せず bracket で囲み、無効なら `\n→\r` 変換して送信。Devin CLI の `raw` 指定を廃止し `paste` に統一
- **構造リファクタリング**（R0〜R4）: store を Single Source of Truth に、設定のアトミック書き込み、コマンド定義の静的検査、エラーハンドリングの厳格化
- **プレビュー分離**（Phase 2）: プレビューをメインエリアから分離し、CSP によるスクリプト実行制限を強化

### バグ修正

- ペイン分割時の surface ノード rescue と絶対位置指定
- タブ閉じるボタン・通知ドット位置・スクロール保存・送信/ドラッグ時のフォーカス
- 検索の二重レンダリング・キャンセル・固定文字列検索
- スタートアップ時のクラッシュ・フィルタ復元・ツリー二重描画
- メニューアクセラレータのターミナルキー干渉を停止
- セッション履歴のキャンセル時に新規セッションを開始するよう修正

## インストール（Windows）

`Project Mixer 0.1.7.exe` をダウンロードして実行（インストール不要）。

### NSIS Installer

`Project Mixer Setup 0.1.7.exe` をダウンロードしてインストール。

## システム要件

- Windows 10 / 11 (x64)
