# Project Mixer v0.1.0

VSCode を 5〜8 枚開かなくて済むようにするデスクトップアプリ。

複数プロジェクトのターミナル・ファイル・エディタを1つのウィンドウに集約し、Claude Code / Codex / Devin CLI などの AI エージェントを複数同時に走らせるワークフローを想定しています。

## 主な機能

- **マルチプロジェクト管理** — サイドバーに複数プロジェクトを登録、ワンクリックで切り替え
- **マルチターミナル** — プロジェクトごとに複数タブ（PowerShell / Bash / Zsh / Claude Code / Codex / Devin CLI 等）
- **ファイルツリー + エディタ** — ツリー表示、ダブルクリックでエディタまたはプレビューで開く
- **ファイルプレビュー** — 画像 / HTML / Markdown をアプリ内でプレビュー（Markdown はサニタイズ付き）
- **ファイル操作** — 新規ファイル/フォルダ作成、削除、パスコピー
- **スクラッチエディタ** — 一時メモ→ターミナルへ送信（bracketed paste 対応）
- **クロスプラットフォーム** — Windows / macOS / Linux 対応

## インストール（Windows）

1. `Project Mixer Setup 0.1.0.exe` をダウンロード
2. インストーラを実行（インストール先を選択可能）

## システム要件

- Windows 10 / 11 (x64)
